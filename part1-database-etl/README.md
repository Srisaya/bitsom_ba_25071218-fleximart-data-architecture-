Task 1.1 – Database Schema Design
A normalized relational schema was designed consisting of four core tables:
Customers – stores customer details
Products – stores product information
Orders – records customer orders
Order_Items – captures products included in each order
Primary keys and foreign key relationships were defined to maintain data integrity and represent real-world business relationships.


Task 1.2 – Database Schema Documentation
The schema was documented using:
Entity descriptions with attributes
Relationship explanations (1:M relationships)
Normalization justification (3NF)
Sample data representation
This ensures the design is well-structured, scalable, and free from redundancy.

Task 1.3 – Business Query Implementation
SQL queries were written to answer real business questions such as:
Total customers and sales
Best-selling products
Repeat customers
Monthly sales trends
These queries demonstrate practical use of **JOINs
